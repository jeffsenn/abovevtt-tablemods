My live view table mods for AboveVTT

I have a D&D table we use for live game sessions.

It uses the excellent https://github.com/cyruzzo/AboveVTT

Here are some mods I'm applying to add functionallity to optimize for my table.
My table uses a small Bluetooth keypad, so the key changes are for
simplifying the UI to only a few keys (on the keypad) to cycle through pop-up configuration, 
zoom, character centering, and keys for dice rolling, 

Configure with some sort of Chrome extension that can tweak CSS and JS on a URL.
I use this one (now requires dev mode): https://tenrabbits.github.io/user-js-css-docs/

Set it up for a URL pattern:

https://www.dndbeyond.com/characters*abovevtt=true

Also included here a couple of batch and powerscript files I use to get the windows 
machine booted up and in the right state of running chrome full screen on a character
page I devote to the map table.  If you use this check the character id in 
autoopentable and change it to yours.  Also a script to shut it down with a key press.
